# Spark export templates

Export templates for [Spark](https://playtime.studio), the game engine by Playtime Studio.
Export templates are the per-platform game runtimes the editor packages a project with when it exports a game.

The Spark editor downloads these itself from
**Editor > Manage Export Templates > Download and Install**. Each
[release](https://github.com/PlaytimeStudio-Software/Spark-Engine-Releases/releases) is tagged with the
engine version (for example `4.7.2.stable`) and contains one
`Spark_v<version>_export_templates.tpz` file, which can also be installed manually with
**Install from File**.

Spark is based on the [Godot Engine](https://godotengine.org) (MIT license).
