# Playtime Spark export templates

Export templates for [Playtime Spark](https://playtime.studio), the game engine of Playtime Studio.
Export templates are the per-platform game runtimes the editor packages a project with when it exports a game.

The Playtime Spark editor downloads these itself from
**Editor > Manage Export Templates > Download and Install**. Each
[release](https://github.com/PlaytimeStudio-Software/Playtime-Engine-Releases/releases) is tagged with the
engine version (for example `4.7.2.stable`) and contains one
`Playtime_Spark_v<version>_export_templates.tpz` file, which can also be installed manually with
**Install from File**.

Playtime Spark is based on the [Godot Engine](https://godotengine.org) (MIT license).
