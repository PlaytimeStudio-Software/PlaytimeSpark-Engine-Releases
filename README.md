# Playtime Engine downloads

Downloads for [Playtime Engine](https://playtime.studio), the game engine of Playtime Studio.
The engine source code is private; this repository only hosts release files.

See [Releases](https://github.com/PlaytimeStudio-Software/Playtime-Engine-Releases/releases) for:

- **Windows installer** (`PlaytimeEngine-<version>-setup-x86_64.exe`): installs the editor.
- **Export templates** (`Playtime_Engine_v<version>_export_templates.tpz`): needed to export games.
  The editor downloads these itself from **Editor > Manage Export Templates > Download and Install**.

## Installing on Windows

1. Download the installer from the latest release and run it.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
   This appears because the installer is not code-signed yet.
3. Start Playtime Engine from the Start Menu.

Playtime Engine is based on the [Godot Engine](https://godotengine.org) (MIT license).
